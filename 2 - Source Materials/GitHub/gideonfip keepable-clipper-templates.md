A collection of [Keepable](https://github.com/gideonfip/keepable) web clipper templates. Built to work together with your Keepable database.

## Templates

| Template | Trigger | Path |
| --- | --- | --- |
| GitHub | `https://github.com/` | `2 - Source Materials/GitHub` |
| Substack Post (Long-Form) | `https://substack.com/home/post` | `2 - Source Materials/Long-Form` |
| Substack Notes | `https://substack.com/@` | `2 - Source Materials/Substack Notes` |
| Reddit | `https://www.reddit.com/`, `https://old.reddit.com/`, `https://reddit.com/` | `2 - Source Materials/Reddit` |
| YouTube | `https://www.youtube.com/` | `2 - Source Materials/YouTube` |
| Twitter/X | `https://x.com/`, `https://twitter.com/` | `2 - Source Materials/X Tweets` |

## Properties

All templates capture:

- **title** - Page title
- **source** - Original URL
- **author** - Author(s) as wikilinks (multitext)
- **published** - Publication date
- **created** - Date clipped
- **description** - Page description
